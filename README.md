# MOKA Garut Website

Website for Paguyuban Mojang Jajaka Kabupaten Garut, covering the organization, programs, news, and recruitment.

## Features

- Responsive landing experience
- Program and recruitment sections
- News cards from external article metadata
- Smooth scrolling and motion effects
- Reusable UI components

## Stack

`Next.js 15` `React 19` `TypeScript` `Tailwind CSS 4` `Prisma` `Cheerio` `Motion` `Lenis` `Radix UI`

## Development

```bash
npm install
npm run dev
```
