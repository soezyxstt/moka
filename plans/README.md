## Prinsip dan Aturan Eksekusi

1. **Baseline dan Drift Check**: Baseline acuan untuk perbandingan drift git adalah commit `3874ede` (Replace Prisma with Turso and Drizzle).
2. **Integritas Public Site**: Public site (`src/app/*` dan komponen publik) merupakan referensi visual. Untuk rilis berikutnya, edisi 2025 tetap menjadi edisi publik aktif dan 2026 tetap draf sampai kontennya siap.
3. **Pemisahan Boundary**: Operator meminta produksi diperbarui setelah kesiapan lokal. Rekonsiliasi data dan deployment tetap harus memakai target database dan project deployment yang dikonfirmasi persis, snapshot yang dapat dipulihkan, serta laporan perubahan yang ditinjau. Otorisasi lokal tidak memberi izin untuk menulis database remote atau deploy.
4. **Authoring Admin**: Form CMS dan antarmuka admin menggunakan komponen reusable (`src/components/admin/primitives.tsx`), radix primitives, Manrope untuk heading, Inter untuk teks, palet warna brand (`brand` dan `highlight`), serta tanpa em dash atau en dash.
5. **Transaksionalitas & Audit**: Setiap operasi penulisan (write) pada CMS wajib melalui server action dengan validasi skema, otorisasi `requirePermission`, transaksi Drizzle, pencatatan `appendAuditLog`, dan `revalidatePath`.
